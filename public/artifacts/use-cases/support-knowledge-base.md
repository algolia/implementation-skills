# Support Knowledge Base Bundle Guide

Use this guide for article, documentation, troubleshooting, and deflection experiences where freshness, permissions, answer quality, and escalation matter.

## Start Prompt

```text
Use the Algolia skills library to plan a support knowledge-base experience. Start with article structure, hierarchy, permissions, freshness, and chunking. Then define query and deflection events, search and autocomplete UX, NeuralSearch and Agent Studio readiness, escalation, and launch QA.
```

## Priority Decisions

1. Decide whether records represent pages, sections, headings, procedures, or chunks.
2. Preserve canonical URL, hierarchy, product, version, locale, audience, and freshness metadata.
3. Define helpfulness, article click, successful deflection, escalation, and feedback events.
4. Keep restricted or internal content isolated from public experiences.
5. Require citations, fallback behavior, and escalation for generative answers.

## Required Outputs

- Content indexing and freshness contract.
- Search, feedback, and deflection event taxonomy.
- Synonym, query, and no-result test set.
- NeuralSearch or Agent Studio readiness report when applicable.
- Launch QA report covering permissions, citations, and escalation.

## Launch Gates

- Current, deprecated, localized, and restricted content resolve correctly.
- Feedback and deflection measurement is attributable and interpretable.
- AI answers remain grounded and provide a safe fallback.
- Users can recover from no results and reach human support when needed.
