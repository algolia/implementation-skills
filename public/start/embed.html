2Install the skills

Select your AI tool, then follow its installation steps.

Install individual skill ZIPs in the Claude app:

  1. Settings → Capabilities → turn on Code execution and file creation.

  2. Customize → Skills → + → Create skill → Upload a skill.

  3. Select an individual skill ZIP. Repeat for each skill you want to install.

  4. Type / in the message box and check that the skill appears.

Upload an individual skill ZIP. The uploader accepts one skill at a time, so do not upload the full-library ZIP here.

Run these commands from the directory containing the full-library ZIP. They copy the skill folders into your Claude Code skills directory.

$ unzip algolia-skills-library.zip -d /tmp/alg
$ mkdir -p ~/.claude/skills
$ cp -R /tmp/alg/algolia-* ~/.claude/skills/

Start a Claude Code session and enter /algolia-discovery-planning.

Place the full-library ZIP in your project directory. Open a terminal in that directory and run:

$ unzip algolia-skills-library.zip -d /tmp/alg
$ mkdir -p .cursor/skills
$ cp -R /tmp/alg/algolia-* .cursor/skills/

In Cursor, enter /algolia-discovery-planning, or use @algolia-discovery-planning to attach the skill.

Place the full-library ZIP in your project directory. Open a terminal in that directory and run:

$ unzip algolia-skills-library.zip -d /tmp/alg
$ mkdir -p .agents/skills
$ cp -R /tmp/alg/algolia-* .agents/skills/

In Codex, use /skills to check the list, then enter $algolia-discovery-planning to use the skill.

Sidebar → Plugins → Plugin Directory → Skills → Create → Upload from your computer. Add one skill at a time. ChatGPT scans each upload, so a skill can come back Needs Review or Blocked before you can use it.

Skills are generally available on Business, Enterprise, Healthcare and Edu — but on Enterprise and Edu an admin has to switch them on. Skills also don't sync between the desktop app and web, so add them in both.

Place the full-library ZIP in your project directory. Open a terminal in that directory and run:

$ unzip algolia-skills-library.zip -d /tmp/alg
$ mkdir -p .github/skills
$ cp -R /tmp/alg/algolia-* .github/skills/

In Copilot Chat, enter /algolia-discovery-planning.

These follow the open Agent Skills spec, which standardises the skill folder itself. Each tool still decides where it looks for one, so try the most widely read path first:

$ mkdir -p .agents/skills
$ cp -R algolia-* .agents/skills/

That works in Codex, Cursor, Copilot, Gemini CLI, Antigravity and Devin Desktop (formerly Windsurf). Two tools need their own location: Claude Code reads ~/.claude/skills/, and Kiro reads .kiro/skills/.

Check your installation: Find algolia-discovery-planning in your tool’s skill list. If it does not appear, check the folder location and the troubleshooting section below.

3Start a task

Copy this prompt into your AI tool. Add a sentence about what you want to build or review.

Use the Algolia Discovery Planning skill to help me choose the right implementation path.

Ask me only the questions you need to understand my goal, my data, my search UI, my events, and my launch risk. Assume I may not know which technical details matter yet.

Then recommend the next Algolia skill to use, the smallest useful first milestone, and the validation artifact I should create.

Answer the questions that apply. The agent should recommend a next step and a skill for your task.

When to use it

Use these examples to choose a skill for a specific task.

Plan a new implementationPlan your data, events, search interface and launch checks before implementation.algolia-discovery-planning
Review an existing implementationReview settings and the search experience for issues such as ranking, facets and missing events.algolia-audit
Investigate search relevanceReview ranking, searchable attributes, facets, synonyms and rules.algolia-index-configuration
Plan click and conversion eventsDefine and validate the events needed for analytics and personalization.algolia-events-insights
Prepare for launchCheck the implementation and record what has and has not been verified.algolia-release-qa
Set up NeuralSearchPlan the data and event requirements for NeuralSearch.algolia-neuralsearch
Plan a migrationDefine the record shape and objectID strategy before moving data.algolia-data-modeling
What good output looks like
  • It asks for the information needed to make a recommendation.
  • It identifies the next steps and their order, such as data, events, settings, UI and launch checks.
  • It suggests useful artifacts, such as a record contract, event plan or launch checklist, when appropriate.
  • It identifies what it could not verify, including account settings it cannot access.
  • It records assumptions that need a decision or follow-up.
Add live account access (optional)

Skills provide instructions to your agent. To let it inspect your Algolia account, connect the official tools and configure their access:

# live analytics, index inspection
$ claude mcp add --transport http algolia https://mcp.algolia.com/mcp

# indices, settings, rules, synonyms, records
$ brew install algolia
Start with a non-production app. Check the permissions you grant: an agent with write access can change your index.
If something doesn't work
  • Nothing happens. Check SKILL.md sits at the top level of the skill folder. Unzipping often creates a doubled folder — look for algolia-events-insights/algolia-events-insights/.
  • Claude rejected the ZIP. Upload individual skill ZIPs, not the full library. If one is still rejected, unzip it and re-zip just the algolia-… folder.
  • Can't use Skills in Claude. Skills need code execution — turn on Settings → Capabilities → Code execution and file creation first.
  • Some load, others don't. Codex budgets its startup skill list to 2% of the model's context window (8,000 characters if that's unknown). Past that it shortens descriptions, then omits skills and warns you. Install just the ones you need.
  • The agent skips the planning step. Name the skill explicitly using your tool’s invocation method, for example: /algolia-discovery-planning.
